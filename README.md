## Installation
> [!CAUTION]
> Do not install this OS on your main computer. It is built to run natively only on my specific hardware setup. I am not responsible for any system damage or data loss.
1. Download [Rufus](https://rufus.ie/en/)
2. Download The OS in [Releases](https://github.com/PotatoIsCoolio/TatOS/releases)
3. Create a bootable USB with Rufus
4. Plug it into PC and boot into the USB
